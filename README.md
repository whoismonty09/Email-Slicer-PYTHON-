# Email Slicer (Python)

## Description
This project is a simple Email Slicer built using Python. It takes an email address as input from the user and separates it into two parts: username and domain name. This project helps in practicing string manipulation and user input handling in Python.

## Features
- Extracts username from email address
- Extracts domain name from email address
- Simple and user-friendly command-line interface
- Basic validation for email format

## Technologies Used
- Python
